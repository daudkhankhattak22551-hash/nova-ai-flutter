# 🚀 Nova AI – Flutter AI Assistant

Nova AI is a modern AI assistant mobile application built with **Flutter**.  
It provides a clean, responsive and user-friendly interface for interacting with AI.

## ✨ Features

- 🤖 AI Assistant Chat
- 💬 Modern Chat Interface
- 🎨 Clean & Responsive UI
- 📱 Flutter Mobile Application
- ⚡ Fast & Smooth User Experience
- 🔐 User-Friendly Authentication UI
- 📂 Organized Flutter Project Structure

## 🛠️ Technologies Used

- Flutter
- Dart
- Firebase
- Google Fonts
- GetX
- Android Studio
